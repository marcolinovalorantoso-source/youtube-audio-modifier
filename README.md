# 🔊 YouTube Audio Control Modifier

An advanced Google Chrome extension (Manifest V3) that converts YouTube's default volume scale to a **natural logarithmic curve (dB scale)**, includes a **Master Volume Attenuator Slider**, and supports **5 languages (IT, EN, FR, DE, AR)** with RTL layout support.

---

## ✨ Key Features

- 🎧 **Logarithmic Volume Scale**: Intercepts YouTube volume control and maps it to a natural logarithmic decibel curve.
- 🎚️ **Master Volume Attenuator**: Slider allows lowering master volume from `0 dB` (100% full volume) down to `-50 dB` (0.3% near silence).
- 📺 **Full YouTube & YouTube Shorts Support**: Works seamlessly across standard YouTube watch pages, playlists, and YouTube Shorts (`/shorts/...`).
- 🌐 **Multi-Language UI (i18n)**:
  - 🇮🇹 **Italiano** (Default)
  - 🇬🇧 **English**
  - 🇫🇷 **Français**
  - 🇩🇪 **Deutsch**
  - 🇸🇦 **العربية** (Arabic with full RTL layout support)
- 🎨 **Sleek Dark Mode UI**: Clean, responsive popup interface.

---

## 🚀 Installation

1. Clone or download this repository:
   ```bash
   git clone https://github.com/marcolinovalorantoso-source/youtube-audio-modifier.git
   ```
2. Open Google Chrome and go to `chrome://extensions`.
3. Enable **Developer mode** in the top right corner.
4. Click **Load unpacked** (*Carica estensione non pacchettizzata*) and select the extension directory.
5. Open [YouTube](https://www.youtube.com) or [YouTube Shorts](https://www.youtube.com/shorts/)!
